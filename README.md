# cves-autotriager

Automated triage tooling for CVEs.

## Requirements

- Python >= 3.10
- [Poetry](https://python-poetry.org/) >= 2.0

## Setup

```bash
poetry install
```

## Usage

```bash
poetry run cves-autotriager --help
```

Parse a directory of Trivy JSON reports and build a triage prompt:

```python
from cves_autotriager import CVEPromptBuilder, TrivyReportParser

cves = TrivyReportParser("trivy-reports/canonical").to_dataframe()
prompt = CVEPromptBuilder().build("CVE-2026-45623", cves)
print(prompt)
```

Store the parsed dataframe in a local SQLite database:

```python
from cves_autotriager import SQLiteClient, write_dataframe_to_sqlite

client = SQLiteClient("data")
database = client.get_database("triage")
table = database.create_table(
	"triage_results",
	[("id", str), ("severity", str), ("score", float)],
)
table.insert(["CVE-2026-45623", "HIGH", 8.1])

for row in table.rows():
	print(row)

rows_written = write_dataframe_to_sqlite(cves, "data/cves.db")
```

Cache NVD enrichment results locally:

```python
from cves_autotriager import NVDEnricher

nvd_cache = database.create_table(
	"nvd_cache",
	[("id", str), ("nvd_description", str), ("nvd_severity", str)],
)
enriched_cves = NVDEnricher(nvd_cache).enrich(cves)
```

Existing cache entries are returned without an NVD request. Successful new
responses are inserted into the table before enrichment continues.

Compare CVE analyses from multiple LangChain models:

```bash
export OPENAI_API_KEY="..."
export ANTHROPIC_API_KEY="..."

poetry run python llm.py data/1.11-ubuntu2 CVE-2026-45623 \
	--model openai:gpt-5.4-mini \
	--model anthropic:claude-sonnet-4-6 \
	--judge-model openai:gpt-5.5
```

Each `--model` receives the same prompt generated by `CVEPromptBuilder`. The
judge receives that prompt and all labeled responses, and the command prints a
JSON document containing the prompt, candidate responses, and comparison. Model
credentials are read by their LangChain providers from environment variables.

The dataframe helper replaces the `cves` table by default. Pass
`if_exists="append"` to retain existing rows.

The editable prompt template is in
`cves_autotriager/resources/triage_prompt.txt`.

poetry run pytest
